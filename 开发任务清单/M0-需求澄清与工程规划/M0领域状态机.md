# M0 领域状态机

## 1. 账号状态机

| 当前状态 | 事件 | 前置条件 | 下一状态 | 说明 |
|---|---|---|---|---|
| 启用 | 登录 | 密码正确、未锁定 | 启用 | 签发 JWT；若需改密则进入受限会话 |
| 启用 | 员工离职 | 员工状态改为离职 | 停用 | 事务内停用账号 |
| 停用 | 登录 | 任意 | 停用 | 拒绝登录 |
| 启用 | HR 停用 | ADMIN 操作 | 停用 | 立即拒绝新请求 |
| 停用 | HR 启用 | 员工仍在职 | 启用 | 恢复登录 |

## 2. 请假单状态机

```text
草稿 ──提交──> 待审批 ──通过──> 已通过
  │             │  │
  │             │  └─驳回──> 已驳回
  │             └─撤销──> 已撤销
  └─删除/放弃（仅前端草稿，可选）
```

| 当前状态 | 允许事件 | 操作者 | 下一状态 | 必须执行的动作 |
|---|---|---|---|---|
| 草稿 | 提交 | 员工 | 待审批 | 重做日期、余额、重叠校验；确定审批人；创建待办消息 |
| 待审批 | 撤销 | 申请人 | 已撤销 | 释放待占用年假；记录审计；通知审批人 |
| 待审批 | 通过 | 当前审批人/ADMIN | 已通过 | 事务内写审批记录、联动考勤、更新汇总、通知员工 |
| 待审批 | 驳回 | 当前审批人/ADMIN | 已驳回 | 写审批意见、释放待占用年假、通知员工 |
| 已通过 | 任意重复审批 | 任意 | 已通过 | 拒绝并返回状态冲突 |
| 已驳回/已撤销 | 任意审批 | 任意 | 不变 | 拒绝并返回状态冲突 |

补充规则：

- 审批通过前必须再次执行重叠校验，避免并发申请造成重复占用。
- 请假联动考勤按工作日拆分；已存在手工调整的考勤记录不得静默覆盖，应记录冲突并进入 HR 处理。

## 3. 工资条状态机

```text
无记录 ──试算──> 草稿 ──确认发布──> 已发布
                                  │
                                  └──补发/修正──> 补发记录
```

| 当前状态 | 事件 | 操作者 | 下一状态 | 约束 |
|---|---|---|---|---|
| 无记录 | 月度试算 | ADMIN | 草稿 | 同一员工同一月份只保留一个有效草稿 |
| 草稿 | 重新试算 | ADMIN | 草稿 | 覆盖草稿前记录计算版本和时间 |
| 草稿 | 发布 | ADMIN | 已发布 | 发布后字段不可修改，创建员工通知 |
| 已发布 | 修改金额 | 任意 | 不变 | 禁止直接更新，必须创建补发/修正记录 |
| 已发布 | 查询 | ADMIN/本人 | 不变 | 执行全员/本人行级权限 |

## 4. 考勤记录状态机

| 当前状态 | 事件 | 下一状态 | 说明 |
|---|---|---|---|
| 无记录 | 上班打卡 | 缺卡或待判定 | 只有上班卡时尚未完成全天判定 |
| 无记录/已有记录 | 下班打卡 | 正常/迟到/早退/缺卡 | 取最早上班卡和最晚下班卡后重算 |
| 任意自动状态 | 审批通过的请假联动 | 请假 | 仅覆盖对应请假日期，保留原始打卡信息 |
| 任意自动状态 | HR 手工调整 | 调整后的状态 | 必须有调整说明和审计日志 |
| 请假/调整状态 | 重复自动计算 | 保持人工优先 | 不得覆盖 HR 已调整结果 |

## 5. Agent 高风险动作状态机

```text
识别请求 → 参数待确认 → 员工确认 → 调用业务 API → 返回结果
                         └─取消/超时──> 不执行
```

- 查询类操作可直接调用，但仍需绑定当前登录员工身份。
- 发起请假属于变更操作，必须展示解析后的类型、日期、时长和事由并二次确认。
- 任何工具调用失败、权限不符或参数不完整，都不得产生业务写入。
