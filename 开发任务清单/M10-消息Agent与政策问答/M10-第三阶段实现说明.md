# M10 第三阶段：业务工具调用实现说明

## 已实现范围

- M10-09：本人考勤、本人年假余额、本人请假记录、本人已发布工资条、本人档案五个只读工具。
- M10-10：本人请假提交的参数解析、预览、一次性确认令牌和事务落库。
- 工具注册表固定在后端，员工身份从 JWT 对应的服务端用户注入；请求和模型均不能传入 `employee_id`。
- 工具结果使用后端固定模板，不经过 LLM 改写敏感工资数据。

## 部署与迁移

```powershell
docker compose build backend frontend
docker compose up -d backend frontend nginx
docker compose exec backend alembic -c alembic.ini upgrade head
```

本阶段新增迁移 `0007_agent_tools`，创建 `agent_action` 表。请确认 `backend/.env` 中 `HR_AGENT_ENABLED=true`，并先完成 M10 第一、二阶段的向量模型和 DeepSeek 配置。

## 使用约定

- 查询示例：`查询我 2026-10 的考勤`、`我的年假余额`、`查询我的工资条`、`查看我的档案`。
- 请假示例：`申请 2026-10-20 至 2026-10-21 年假，原因：个人事务`。
- Agent 返回预览和短期确认令牌，前端点击“确认提交请假”后调用 `POST /api/agent/conversations/{id}/confirm-leave`。
- 令牌绑定用户、会话和参数哈希，10 分钟有效且只能使用一次；确认前不会新增 `leave_request`。
- 不支持代他人查询、审批、撤销、修改薪资或其他未注册工具。
