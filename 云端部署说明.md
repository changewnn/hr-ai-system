# HR 系统云端部署说明

当前方案使用 Linux 云服务器 + Docker Compose。PostgreSQL 使用 `pgvector/pgvector:pg16`，Redis 使用 `redis:7-alpine`，两者只通过 Compose 内部网络访问。生产域名示例为 `wunannan.cn`，由 Nginx 终止 HTTPS。

## 服务器要求

- Ubuntu 22.04/24.04 或同等 Linux 发行版
- Docker Engine 和 Docker Compose Plugin
- 至少 2 vCPU、4 GB 内存
- 云硬盘用于 Docker 数据目录
- 防火墙仅开放 SSH、80、443
- 不开放 5432、6379、8000、5173

## 首次部署

```bash
git clone <repository-url>
cd hr-ai-system
cp .env.docker.example .env
vi .env

docker compose config
docker compose up -d postgres redis
docker compose exec postgres psql -U langchain_user -d hr_ai_system -c "CREATE EXTENSION IF NOT EXISTS vector;"
docker compose up -d --build backend frontend nginx
docker compose run --rm backend alembic -c alembic.ini upgrade head
docker compose exec backend python scripts/seed.py
docker compose exec backend python scripts/init_admin.py --username admin --password "生产管理员密码"
```

## HTTPS 与域名

将 `wunannan.cn` 和 `www.wunannan.cn` 的 DNS A 记录解析到云服务器公网 IP，并允许防火墙入站访问 80/443。生产配置位于 `docker-compose.prod.yml` 和 `deploy/nginx/https.conf`。

首次申请 Let's Encrypt 证书：

```bash
mkdir -p deploy/certbot/www deploy/certbot/letsencrypt
docker compose up -d backend frontend
docker compose stop nginx
docker run --rm -p 80:80 \
  -v "$PWD/deploy/certbot/letsencrypt:/etc/letsencrypt" \
  certbot/certbot certonly --standalone \
  --email admin@wunannan.cn --agree-tos --no-eff-email \
  -d wunannan.cn -d www.wunannan.cn
```

证书申请成功后启动生产 Nginx：

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d nginx
docker compose -f docker-compose.yml -f docker-compose.prod.yml config
curl -I http://wunannan.cn
curl -I https://wunannan.cn
```

生产配置会将普通 HTTP 请求返回 301 并跳转到 HTTPS，同时保留 `/.well-known/acme-challenge/` 用于证书校验。当前本地开发仍使用默认 Compose 配置和 `http://127.0.0.1:8080`。

续期示例：

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml stop nginx
docker run --rm -p 80:80 \
  -v "$PWD/deploy/certbot/letsencrypt:/etc/letsencrypt" \
  certbot/certbot renew
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d nginx
```

生产 `.env` 必须设置：

```env
APP_ENV=production
HR_DEBUG=false
HR_SECRET_KEY=至少32位的随机密钥
```

## 升级

```bash
git pull
docker compose build
docker compose run --rm backend alembic -c alembic.ini upgrade head
docker compose up -d
```

不要在生产环境执行：

```bash
docker compose down -v
```

## 持久化与备份

Compose named volumes：

- `postgres_data`：业务数据和 pgvector 数据
- `redis_data`：Redis AOF 数据
- `knowledge_data`：政策文件

PostgreSQL 备份示例：

```bash
mkdir -p backup
docker compose exec postgres pg_dump -U langchain_user -d hr_ai_system -Fc > backup/hr_ai_system_$(date +%Y%m%d%H%M%S).dump
```

生产环境应将备份上传到对象存储，并对云硬盘启用快照。Redis 不是正式业务数据的唯一存储，PostgreSQL 才是业务数据源。

## 健康检查

```bash
docker compose ps
docker compose exec postgres pg_isready -U langchain_user -d hr_ai_system
docker compose exec redis redis-cli --no-auth-warning -a "$REDIS_PASSWORD" ping
curl http://127.0.0.1:8080/api/health
```
